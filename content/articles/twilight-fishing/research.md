### 3記事以上で共通する「釣れる理由」の内訳

上位記事は理由を **3〜5項目に分解** して解説している。以下の5点セットが最も一般的。

1. **食物連鎖の活性化** — プランクトンが浮上→小魚が集まる→捕食魚が動く
2. **水温・代謝の変化** — 朝は水温上昇、夕は低下。代謝が活発になる
3. **薄明（ローライト）** — 暗すぎず明るすぎない。エサが見えて敵に見えにくい
4. **警戒心の低下** — 人の活動が少なく、魚が大胆になる
5. **潮の動きとの重なり** — 潮目・大潮と合わさると相乗効果

## 6. 競合との差別化戦略（ツリナラ向け）

### 上位記事の弱点

1. **浅い記事が混在** — 550字〜1,100字の記事は網羅性不足（tsuttarou, Cybangler）
2. **釣り種特化と総合記事の混在** — 「マズメ釣り」で検索するとアジング特化記事も混ざる
3. **実践的な判断基準が弱い** — 「確認しよう」で終わり、具体的なGO/NG基準が少ない
4. **図表・チェックリストが少ない** — テキスト中心で視覚的に整理された記事が少ない

### ツリナラ記事で勝つための方針

| 施策 | 内容 |
|------|------|
| **網羅性** | 必須18トピックをすべてカバー（4,000字以上） |
| **実用性** | 時間帯別カラー表、潮×マズメ相性表、5分前チェックリスト |
| **構造化** | FAQセクション + FAQPage構造化データ |
| **内部リンク** | 総合記事（ハブ）→ シーバス/アジング/ジギング（スポーク） |
| **独自性** | 天候別判断表、地域別時間比較、安全チェックリスト |
| **E-E-A-T** | 条件（時期・場所・天候）を明記。更新日・著者情報 |
